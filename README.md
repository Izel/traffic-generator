<h1>Streaming data Generator for GCP Pub/Sub</h1>
This project pushed messages generated by bitcoin transactions obteinerd from <a href="https://www.blockchain.com/">https://www.blockchain.com/</a> and push them into a pub/sub topic.  This project runs locally.

<h2>Configuration</h2>
<ol>
  <li><b>Create a virtual environment </b><br/> 
  <code>pip install virtualenv </code>
  </li>
  <li><b>Create a virtual environment </b><br/> 

    In your project folder execute the commnd below <br/>
    <code> python -m venv &lt;folder_name&gt;  </code><br/>
    <a href=https://python.land/virtual-environments/virtualenv>https://python.land/virtual-environments/virtualenv</a>

  </li>
  <li><b>Activate the virtual environment</b> <br/> 

    In your project folder execute the commnd below <br/>
    <code> &lt;folder_name\&gt;/Scripts/activate.bat  // for Windows cmd console</code> <br/>
    <code> &lt;folder_name\&gt;/Scripts/Activate.ps1  // for Windows Powershell console</code> <br/>
    <code> source &lt;folder_name\&gt;/bin/activate // for Linux and MacOs </code> <br/>
    <a href=https://python.land/virtual-environments/virtualenv>https://python.land/virtual-environments/virtualenv</a>

  </li>
  <li>Install GCP CLI </li>
  <li><b>Install the project dependencies</b><br/> 

    <code> pip install -r requirements.txt </code>

  </li>
  <li><b>Initialize your cloud</b>

    <code>gcloud init</code>

  </li>
  <li><b>Authenticate</b><br/> 

    <code>gcloud auth login</code>

  </li>
  <li>Create a Service Account and grant <code>pubsub.admin</code> permissions </li>
  <li>Create a topic and a sub-topic</li>
  <li>Generate a key for the service account and store the <code>.json</code> file in the <code>secret</code> folder</li>
  <li>Modify the <code>env.env</code> file with your project values and save it as <code>.env</code></li>
  <li>Modify the <code>.gitingore</code> file to ignore your key file.</li>
</ol>
<i>*The service account key file and the <code>.env</code> file must be kept locally. Do not push them to repos.</i>

<h2>Run the Project</h2>
Execute the <code>generator.py</code> script : <code>python generator.py</code>
