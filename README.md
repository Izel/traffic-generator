# Streaming data Generator for GCP Pub/Sub

This project pushed messages generated by bitcoin transactions obteinerd from [https://www.blockchain.com](https://www.blockchain.com) and push them into a pub/sub topic.  This project runs locally.

## Configuration

### Create a virtual environment 

Execute pip to install virtual env
```shell 
pip install virtualenv 

```
  
Create a virtual environment in your project folder by executing the commnd below. For more details about virtualenv visit [https://python.land/virtual-environments/virtualenv>https://python.land/virtual-environments/virtualenv](https://python.land/virtual-environments/virtualenv>https://python.land/virtual-environments/virtualenv)
```shell 
  python -m venv folder_name  
```

Activate the virtual environment
```shell    

    folder_name/Scripts/activate.bat  // for Windows cmd console
    folder_name/Scripts/Activate.ps1  // for Windows Powershell console
    source folder_name/bin/activate // for Linux and MacOs 

```
Install GCP CLI
Install Terraform
Install the project dependencies
```shell 
  pip install -r requirements.txt
  ```

Initialize your cloud
```shell 
gcloud init

```

Authenticate by executing the comand below and visiting the link.
```shell 
  gcloud auth login
```

Generate the Application Default Credentials

```shell
  gcloud auth application-default login
  ```

In folder infra/environments/dev execute the commands below

```shell
  terraform init
  terraform plan -out-tfplan
  terraform apply tfplan
  ```
