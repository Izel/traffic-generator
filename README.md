# Streaming data Generator for GCP Pub/Sub

The aim of this project is to push messages generated by bitcoin transactions obtained from [https://www.blockchain.com](https://www.blockchain.com) into a pub/sub topic.

## 2. Virtual environment configuration

### Create a virtual environment 

Execute pip to install virtualenv
```shell 
pip install virtualenv 

```
  
Create a virtual environment in your project folder by executing the command below. For more details about virtualenv, visit [https://python.land/virtual-environments/virtualenv>https://python.land/virtual-environments/virtualenv](https://python.land/virtual-environments/virtualenv>https://python.land/virtual-environments/virtualenv)
```shell 
  python -m venv folder_name  
```

Activate the virtual environment
```shell    

    folder_name/Scripts/activate.bat  // for Windows cmd console
    folder_name/Scripts/Activate.ps1  // for Windows Powershell console
    source folder_name/bin/activate   // for Linux and MacOs 

```
## 3. Configure the cloud connection
Install GCP CLI

Install Terraform

Install the project dependencies
```shell 
  pip install -r requirements.txt
  ```

Initialise your cloud
```shell 
gcloud init
```

Authenticate by executing the command below and visiting the link.
```shell 
  gcloud auth login
```

Generate the Application Default Credentials
```shell
  gcloud auth application-default login
```
## 4. Project execution
In folder infra/environments/dev execute the commands below
```shell
  terraform init
  terraform plan -out-tfplan
  terraform apply tfplan
```
